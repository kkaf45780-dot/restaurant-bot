# موظف المطعم — نظام الاستقبال الذكي وإدارة المطاعم

**"موظف المطعم"** هو تطبيق ويب متكامل وتطبيق ويب تقدمي (PWA) باللغة العربية (RTL) وبخط `Cairo`، يعمل كموظف استقبال ذكي ومنصة طلب وإدارة متكاملة للمطاعم. يتيح للعملاء التحدث بالعامية المصرية الطبيعية، تصفح المنيو بالأحجام والإضافات، استخدام كوبونات الخصم، متابعة حالة الطلب لحظياً، وتقييم الخدمة وإرسال الطلبات عبر واتساب، مع لوحة تحكم محمية بالصلاحيات لمدير المطعم وفريقه على المسار `/admin`.

---

## واجهات وصفحات التطبيق

### 1. واجهة العميل
- **الصفحة الرئيسية (`/`)**: واجهة ترحيبية تعرض حالة المطعم الحية (مفتوح / مغلق)، أكثر الأطباق طلباً، نبذة عن المطعم، وروابط مباشرة للمنيو والمحادثة الذكية.
- **قائمة الطعام (`/menu`)**: تصفح الأقسام، البحث والفلترة، نافذة تخصيص المنتج (اختيار الحجم، الإضافات المدفوعة والمجانية، وملاحظات التحضير)، وإضافة إلى المفضلة، مع تعديل مباشر لبنود السلة.
- **الموظف الذكي (`/chat`)**: محادثة تفاعلية بالعامية المصرية مدعومة بـ Gemini API مع أزرار سريعة وتحديث تلقائي لسلة الطلبات على الخادم (تتوقف تلقائياً مع رسالة تنبيه عند انقطاع الإنترنت).
- **السلة وإتمام الطلب (`/checkout`)**: مراجعة العناصر وتعديلها مباشرة، اختيار التوصيل للمنزل أو الاستلام من الفرع، تطبيق كوبونات الخصم (`HARA10` أو `WELCOME30`)، التحقق من الحد الأدنى للمنطقة، تسجيل الطلب مع منع التكرار (`idempotencyKey`)، وتجهيز رسالة واتساب منسقة.
- **تتبع الطلب (`/track`) وطلباتي (`/orders`)**: شريط مراحل الطلب السباعي مع تحديثات لحظية (Supabase Realtime + استطلاع دوري)، تقييم الطلب من 1 إلى 5 نجوم بعد التوصيل، وزر **"إعادة الطلب"** لنسخ عناصر الطلب السابق مباشرة إلى السلة.
- **المفضلة (`/favorites`) وعن المطعم (`/about`) والسياسات (`/privacy`، `/terms`)**: الأطباق المحفوظة، فروع المطعم ومناطق التوصيل، وسياسة الخصوصية وشروط الاستخدام.
- **ميزات إضافية**: الوضع الليلي (`الوضع الليلي`)، مشاركة رابط المنيو عبر QR Code، وتثبيت التطبيق كـ **PWA** مع حفظ المنيو محلياً للقراءة فقط عند انقطاع الاتصال.

### 2. لوحة تحكم المدير (`/admin`)
- **نظام صلاحيات الموظفين (RBAC)**: دعم الأدوار الوظيفية التالية على مستوى التبويبات وواجهات البرمجة:
  - `owner` (مالك المطعم): صلاحيات كاملة تشمل الموظفين وإعدادات النظام.
  - `manager` (مدير فرع): إدارة الطلبات والمنيو والتوصيل والمخزون والكوبونات والتقارير والمطعم والموظف الذكي.
  - `cashier` (كاشير واستقبال): الرئيسية، الطلبات، والكوبونات.
  - `kitchen` (فريق المطبخ): الرئيسية ومتابعة/تحديث حالة الطلبات.
- **لوحة التحكم العامة والطلبات**: مؤشرات الأداء اليومية، مخطط المبيعات، استقبال التحديثات الحية عبر Supabase Realtime، تحديث الحالة عبر 7 مراحل مع خصم تلقائي للمخزون عند القبول واسترداده عند الإلغاء، عرض تقييمات العملاء، وتصدير CSV.
- **إدارة القائمة والتوصيل والمخزون والكوبونات**: إدارة شاملة للأصناف والأحجام والإضافات ورفع الصور والمناطق والفروع وحركات المخزون وأكواد الخصم.
- **التقارير والتحليلات**: فلاتر زمنية (**الكل / اليوم / هذا الأسبوع / هذا الشهر**)، الإيرادات، متوسط قيمة الطلب، والأصناف الأكثر والأقل طلباً.

## طريقة التثبيت والتشغيل

### 1. تثبيت الحزم
```bash
npm install
```

### 2. إعداد متغيرات البيئة
انسخ ملف `.env.example` إلى `.env` وأضف القيم المطلوبة:

```env
GEMINI_API_KEY="ضع_مفتاح_Gemini_هنا"
APP_URL="http://localhost:3000"

# إعدادات Supabase (اختياري — في حال تركها فارغة يعمل الوضع التجريبي المحلي تلقائياً)
VITE_SUPABASE_URL=""
VITE_SUPABASE_ANON_KEY=""
SUPABASE_SERVICE_ROLE_KEY=""

# بيانات دخول المدير في الوضع التجريبي المحلي
ADMIN_EMAIL="admin@hara-grill.eg"
ADMIN_PASSWORD="MY_ADMIN_PASSWORD"
ADMIN_SESSION_SECRET="MY_SESSION_SECRET"
```

> **بيانات الدخول التجريبية الافتراضية في الوضع المحلي**: `admin@hara-grill.eg` / `Admin@1234` (كما يمكن للموظفين النشطين مثل `cashier@hara-grill.eg` و `kitchen@hara-grill.eg` الدخول بنفس كلمة المرور التجريبية بصلاحياتهم المحددة).

### 3. تشغيل التطبيق والاختبارات
```bash
# تشغيل خادم التطوير على المنفذ 3000
npm run dev

# فحص الأنواع والبناء
npm run lint
npm run build

# تشغيل اختبارات الوحدة والتكامل الحية (E2E)
npm test
```

## قاعدة البيانات والنسخ الاحتياطي (Supabase & Local Fallback)

- **Supabase (الإنتاج السحابي)**: نفّذ محتوى `supabase/migrations/001_initial_schema.sql` (أو `supabase/schema.sql`) في **SQL Editor** لإنشاء الجداول الـ 13، فهارس الأداء، سياسات الحماية (RLS)، وتفعيل البث اللحظي (`supabase_realtime`) وحاوية التخزين `restaurant-assets`. يُنصح بتفعيل النسخ الاحتياطي اليومي التلقائي (Daily Backups) من لوحة مشروع Supabase.
- **الوضع المحلي (`.data/db.json`)**: عند عدم ربط Supabase، تُحفظ جميع البيانات في `.data/db.json` والصور المرفوعة في `.data/uploads`. لأخذ نسخة احتياطية محلية، انسخ مجلد `.data` دورياً أو استخدم تصدير CSV لبيانات الطلبات من لوحة التحكم.

## البناء والنشر (Deployment / Vercel)

يتضمن المشروع ملف `vercel.json` جاهزاً لتوجيه واجهة React SPA ومسارات `/api/*`:

```bash
npm run build
npm run start
```
